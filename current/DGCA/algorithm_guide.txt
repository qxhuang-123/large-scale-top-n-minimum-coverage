 02 问题、直接交换与单调结构
 设用户集合为 U，候选物品集合为 I，偏好过滤后的候选边集合为 E。每位用户至少有 N 个不同候选。评分
 sui 是输入的有限实数，对应原文的 Rui*；本稿省略固定过滤参数 α。




 原问题在 K(x)≥D 的约束下最大化 S(x)。初始解 x0 为每位用户独立选取得分最高的 N 个物品；记 S0=S(x0)、
 K0=K(x0)、C0=C(x0)，以及用户初始集合 Su0。初始 Top-N 是忽略覆盖约束时的最优解。

 一个合法的直接交换




 供给物品 i 至少被推荐两次，所以撤掉一次仍被覆盖；新物品 j 原先完全未覆盖，因此不会与用户现有推荐
 重复。每个用户的推荐数量保持 N。它对应原文的一用户残量路径 t→i→u→j→c。

 为什么旧信息可以复用

   状态                         直接交换全过程中的变化


   初始已覆盖物品                    计数只下降，并始终至少为 1；初始单覆盖物品永远不能作为供给。


   新覆盖物品                      从计数 0 变为 1，此后始终为 1；不会再加入其他用户，也不会被撤出。


   可撤出的已选边                    只能来自初始 Top-N 中的供给边；这些边只会失效，不会新增。


   未覆盖候选                      集合只缩小；已经覆盖的终点不可能重新变为未覆盖。


 所以每个合法交换都撤掉某条初始 Top-N 边，并加入某个初始未覆盖物品。Top-N 的排序性质给出 sui≥suj
 ，故每步损失非负，总评分不会上升。此结论不要求输入评分本身非负。


  D 的决策规则：在当前全部合法直接交换中选损失最小者。这里“精确”指单步最小值查询；整个直接交换
  序列仍是启发式，不保证原覆盖约束问题的全局评分最优。

 03 供给端与终点的精确聚合
 供给端：每位用户保存最便宜的可撤出推荐



 同时保存达到最小值的原始推荐槽位 pu。把每个用户的 N 个初始槽位按“评分升序、槽位升序”排序，形成固
 定供给池。指针跳过已经被替换的槽位，或对应物品已变为单覆盖的槽位；第一个有效槽位就是精确的最小
 供给。

 被跳过的槽位不会重新有效，所以所有用户供给指针的累计前进次数至多 N|U|。一次交换只需立即刷新交
 换用户；若旧供给物品的计数从 2 降到 1，还需刷新其剩余推荐用户。因此每次最多刷新两个用户的供给状
 态。

 终点：每位用户保存得分最高的未覆盖候选



 候选行按“评分降序、物品编号升序”排列。维护一个行指针，向前跳过已覆盖物品；首个未覆盖候选 ju 即为
 最优终点。所有用户终点指针的累计前进次数至多 |E|。若供给或终点不存在，该用户不能产生直接交换。

 双端聚合恰好给出当前最优直接交换



 固定用户 u 后，供给 i 和未覆盖终点 j 可以独立选择：j 不在任何当前推荐中，故它不会与 i 或该用户其他已
 选物品冲突。因此在该用户内最小化 sui-suj，恰好等于最小供给分数减去最大终点分数；再对用户取最小值
 即可。

 04 单调下界与惰性堆查询
 供给集合和终点集合只缩小，使每位用户的最小供给分数不下降、最高未覆盖分数不上升。因此，只要该用
 户仍活跃，其真实最小损失不下降。永久失活的用户按损失为正无穷处理。




 缓存的是下界，不要求所有堆键实时更新
 每个活跃用户在堆中最多一个条目。缓存键来自之前某一状态，故其损失不大于当前真实损失。交换后即时
 刷新最多两个用户的供给值，但其他用户的终点和堆条目可以延迟到被查询时再刷新。

 为与 A-C 版实验保持一致，完整排序键使用（损失、新物品编号、用户编号、供给槽位）。候选行和供给池
 的同分排序固定，因此这个字典序键也单调不减。实现不能只更新损失却忽略用于恢复交换的见证。

 精确查询的四步

   步骤                   操作


   1. 弹出                弹出缓存键最小的用户 u，重新检查供给状态与终点指针。


   2. 删除失活用户            若 u 已无有效供给或未覆盖终点，丢弃其条目；由于单调性，无需重新激活。


   3. 接受或重排             计算当前真实键。若不大于剩余堆的最小缓存键，接受；否则用真实键重新入堆。


   4. 交换后维护             执行交换并刷新受影响供给；为本次被弹出的获胜用户重新查询并按需入堆。其他条目继续作为下
                        界。



 为什么返回的是全局当前最小值
 设 u 的真实键已核实，且不大于任何剩余缓存键。对任意其他活跃用户 v，其缓存键不大于真实键，所以形
 成以下比较链：



 因此 u 在所有当前合法直接交换中最优。相反，若刷新的真实键仍大于另一个用户的缓存下界，尚不能确定
 最优者，必须先重新排序。旧键过小只会增加刷新次数，不会导致漏掉更好的当前交换。


  例如，弹出的旧损失为 0.20，刷新后变为 0.50，而另一个用户的缓存下界为 0.30，就不能立即接受 0.50
  ；应将其重新入堆，再核实 0.30 对应的用户。

 这一查询机制保持 C 版与 D 版在相同 tie-breaking 下的逐步决策一致。区别在于 C 按物品维护候选，D 按用户聚合两端；聚合本
 身不改变动态贪心规则。

 05 完整算法与两种停止模式
 输入为已过滤、行内有序的候选图、评分、N 和目标 D。模式 target 在达到 D 时停止；模式 terminal 继续
 到无直接交换可做，并记录第一次达到 D 的解。论文可以沿用原算法 2 的“双输出”约定。

   01   BGCR-D(E, s, N, D, mode):
   02      x <- independent Top-N; initialize counts and owner summaries
   03      K <- coverage(x); S <- score(x); x_target <- UNDEFINED
   04      if K >= D: record x_target <- x
   05      if mode == target and K >= D: return x_target
   06      build sorted initial-slot pools; RefreshSource(u) for all u
   07      initialize each terminal pointer at its candidate-row start
   08      H <- one valid QueryUser(u) entry per user
   09      while H is not empty:
   10        old <- PopMin(H)
   11        cur <- QueryUser(old.user)
   12        if cur is INVALID: continue
   13        if H is not empty and Key(cur) > Key(Min(H)):
   14          Push(H, cur); continue
   15        (u, i, j, slot) <- witnesses stored in cur
   16        replace i by j in user u; update counts and owners
   17        K <- K + 1; S <- S - cur.loss; append event/history
   18        RefreshSource(u)
   19        if count(i) == 1:
   20          v <- remaining owner of i
   21          if v != u: RefreshSource(v)
   22        if K >= D and x_target is UNDEFINED: record x_target <- x
   23        if mode == target and K >= D: return x_target
   24        next <- QueryUser(u)
   25        if next is valid: Push(H, next)
   26      return x_target, x_terminal <- x
   27
   28   QueryUser(u):
   29      if u has no valid source: return INVALID
   30      advance terminal pointer while its item is covered
   31      if pointer reaches row end: return INVALID
   32      return (a[u] - b[u], terminal, user, source_slot)

 RefreshSource 只沿固定供给池前进，跳过非初始已选边或计数小于 2 的物品。所有源值在交换后即时维护，因此 QueryUser 不
 必重新扫描用户的 N 个推荐。record 表示保存快照或保存可重放的事件位置，不能只是保存随后继续修改的对象引用。


  若堆耗尽而仍未达到 D，只能报告“直接交换启发式未达到目标”。这既不证明 D 对原问题不可行，也不证
  明当前覆盖是全局最大覆盖；长交换链仍可能增加覆盖。

 记 n=|U|、m=|I|、M=|E|，T 为实际接受的直接交换数；R 为刷新后重新入堆而未立即接受的次数。以下
 复杂度针对第 5 页的一用户一条目实现，采用二叉堆和 O(1) 所有者更新。

 累计分析，不能套用原版的一次物品扫描分析
 供给池排序需要 O(nN log(N+1))，供给指针累计前进至多 nN；终点指针累计前进至多 M。一个用户永久失
 活时最多丢弃一次条目，共至多 n 次。每次接受交换最多引起两次供给刷新，并为获胜用户重新入堆一次。

 ，它必然可以被接受。严格增加可归因于自上次存键以来新的供给指针或终点指针前进；同一用户的同一次
 前进不会被重复归因。故：

 07 命题 1：紧的 1/2 终止覆盖保证

  命题 1。设 xGT 是 BGCR-D 运行到不存在合法直接交换时的终止解。设 Kmax 是同一候选图、同一 N 下原
  问题能够达到的最大物品覆盖，则 K(xGT)≥Kmax/2。该因子在最坏情况下不能改进。

 紧例：动态挑选顺序也无法解决没有直接路径的状态
 取 N=1。g+1 位用户都初选物品 a，另有 g 位用户分别初选不同的 b1,…,bg。对每个 l，其中一位 a 用户还可
 选 bl，相应 bl 用户还可选一个独有未覆盖物品 cl；保留一位只能选 a 的用户。初选物品的评分严格高于备选
 评分。

 a 用户没有未覆盖候选，而 b 用户没有可撤出的多覆盖物品，所以初始状态已是直接交换终止状态，覆盖为
 g+1。但把相应 a 用户改为 bl、bl 用户改为 cl，可同时覆盖全部 2g+1 个物品。




 对任意固定 N>1，将每个物品替换成 N 个同类型副本，每位用户初选对应的 N 个副本，覆盖分别变为
 N(g+1) 和 N(2g+1)，比率不变。这也确保紧例从合法的独立 Top-N 初始解出发。

 达到每个 D≤Kmax/2。该命题延续原稿 Theorem 6 和 Appendix A.2 的结论 [1]。

 08 评分保证的基础：静态直接交换族
 评分损失分析从初始解 x0 出发。将所有可能的直接交换写成静态元素集合 Ω：



 这是用于证明的概念集合，实现无需显式枚举它。交换集合 Q⊆Ω 可执行，当且仅当满足下面三项约束。

   约束                                        含义


   每条初始已选边 (u,i) 至多使用一次                      同一个初始推荐槽位只能撤出一次。


   每个供给物品 i 至多使用 ri0-1 次                     至少保留该物品的一次推荐，确保它一直被覆盖。


   每个新增物品 j 至多使用一次                           物品一旦被覆盖，就不能再作为直接交换终点。


 必要性来自单调结构。反过来，对满足三项约束的 Q，按任意顺序执行也始终合法：待执行供给边尚未撤出
 ；若还要从 i 撤出一次，当前计数至少为 2；待加入终点尚未被覆盖。用户的一次撤出和一次加入配对，推
 荐数量不变。于是：




 结构引理：加入一个贪心交换，至多移除两个比较交换
 设 G 是已执行的贪心前缀，Q 是与 G 不相交、且 G∪Q 可执行的比较集合。加入下一步合法贪心交换 e 后，
 可以从 Q 中移除至多两个元素，使新前缀与剩余比较集合仍相容。

 供给端最多移除一个：若 Q 中某交换使用同一初始已选边，移除它，同时也减少供给物品总用量；若没有同
 边冲突但物品总撤出数超限，只需移除一个使用该供给物品的 Q 元素。前缀 G 加入 e 本身合法，保证所需移
 除对象可在 Q 中找到。

 终点端最多再移除一个：Q 中至多一个交换使用 e 的新增物品，把它移除即可。若 e 本来就在 Q 中，只需把
 它从“剩余比较集合”移到贪心前缀，不再重复计数。这证明每一步最多消耗两个比较元素。


  这三项约束可写为一个供给侧层状拟阵与一个终点侧分区拟阵的交，属于经典 2-extendible 分析范畴。本
  文需要证明的是本模型如何满足这些约束，以及它们如何导出后续评分损失结论；不应把通用交换原理本
  身称为全新的理论 [2]。

 反例：同一覆盖目标下的损失比可以无界
 取 N=1、0<ε<1/4，候选和评分如下；“不可选”表示没有该候选边。所有用户初选 a，初始覆盖为 1，目标覆
 盖为 3。

   用户                  a                     b                 c


   u1                  1                     1-ε               1-2ε


   u2                  1                     1-2ε              ε


   u3                  1                     不可选               不可选


 动态贪心第一步让 u1 从 a 换到 b，损失 ε；此后 u1 的 b 已是单覆盖，不能再撤出。为了覆盖 c，只能让 u2
 从 a 换到 c，损失 1-ε，总损失为 1。

 最优方案可让 u1 从 a 换到 c、u2 从 a 换到 b，总损失为 4ε。两步本身也都可以直接执行，所以这个反例甚
 至发生在纯直接交换比较族内部。




 这排除了同一新增覆盖下累计损失的统一常数倍保证。它讨论的是“从 Top-N 扣掉的损失”，不能据此推出总
 评分 S(x) 的近似比也无界。该反例不违反命题 2，因为命题 2 只保证同预算下至少获得一半新增覆盖。

  失预算下的新增覆盖保证；这解释了规则的选择，同时保留其作为直接交换启发式的准确定位。

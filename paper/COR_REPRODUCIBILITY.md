# COR reproducibility and submission notes

## Suggested code availability statement

The source code used for data preprocessing, the Gurobi and Gurobi-LP
benchmarks, explicit minimum-cost flow, TPCAR, BGCR, and sensitivity analyses
is publicly available at
https://github.com/qxhuang-123/preference-safe-minimum-coverage. The repository
includes environment requirements, an experiment crosswalk, compiled extension
source, and small result tables. A versioned archival DOI should be inserted
after creating the corresponding Zenodo, Mendeley Data, or Code Ocean record.

## Suggested data availability statement

The experiments use the public Amazon 5-core and Yelp datasets and predicted
user-item scores generated by LETTER. Raw datasets remain subject to their
original terms and are not redistributed in this repository. Instructions for
obtaining or regenerating inputs, the expected local layout, and a tool for
recording file sizes and SHA-256 checksums are provided in `data/README.md`.
